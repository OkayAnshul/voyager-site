How Voyager was built

A one-person Android project built in the open over roughly a year — including one deliberate architectural U-turn and a disciplined, wave-by-wave hardening process.

Aug 2025 · Foundation

Privacy-first from the first commit

Clean-architecture skeleton, Hilt, a Room schema encrypted with SQLCipher from day one, adaptive location sampling, a foreground service, early multi-sensor capture, and the first evidence schema. Encryption was an architectural decision, not a later add-on.

Sep–Dec 2025 · Maturation & a hard look

Repositories, analytics, and an honest self-audit

Repository implementations, analytics rollups, an FTS search schema and the first real use cases — followed by an unusually candid round of self-audit docs that graded the codebase and set up the biggest decision of the project. Phase 8 tackled battery and performance head-on.

Mar 2026 · The V2 rewrite

From “visit-first” to a “stream-first” pipeline

The original timeline detected stops, then guessed the movement between them. V2 inverted the model to a single, serial, explainable pipeline over the raw sample stream — normalise → Kalman-filter → quality-score → dedup → commit-state → segment — with a gap watchdog and crash recovery. This is the spine that makes honest gaps and per-row explainability possible.

Apr–May 2026 · Productization

A product, and a migration wedge

Build flavors, an entitlement layer, a mileage subsystem, Photo Day Story, trip detection, a carbon-footprint engine — and a deliberate go-to-market wedge: Google Timeline import, for people whose cloud Timeline was discontinued. “Lost your Timeline? Bring it home.”

May–Jun 2026 · Hardening in waves

Verify on real travel, then raise to the flagship bar

A single living catalogue drove Waves 0 → 10, ordered by real-world impact. Each feature card carried a “how to travel-test” recipe and a “flagship bar” it had to clear: timeline correctness, place/geocoding trust, a Strava-parity fitness subsystem, a heatmap and Year-in-Review, an accelerometer-signature classifier, and place repeatability. The database schema evolved through thirteen versions, each migration tested.

Jul 2026 · Publishing polish

The final pre-launch pass

A deep correctness audit removed the last unsafe null-assertion, fixed place naming so no “Unknown place” ever reaches the timeline, reworked onboarding, and — for launch — made every feature free while keeping the billing layer dormant for a possible future subscription.

Engineering process, in short

  • Conventional Commits throughout — a legible history across 200+ commits.
  • Docs coupled to code — feature commits land with catalogue updates, so the docs never drift from reality.
  • A written flagship bar per feature, and a habit of testing on real travel — not just unit tests.
  • CI on every PR — per-flavor unit tests, lint, and both flavor assemblies, plus a monthly dependency-security scan.
  • A willingness to make a hard call — the visit-first → stream-first rewrite — when the retrospective said the foundation wouldn't scale.

Voyager is a transparent heuristic engine — it wins by being explainable, private and bundled, not by being a black box.
